SDOH Screening — screen, code, refer

The SDOH Screening page (/sdoh-screening) is a coded social-needs screen (the CMS AHC-HRSN domains: housing, food, transportation, utilities, safety, financial strain, employment, education). What makes it more than a note: a positive answer maps to a billable ICD-10 Z-code and a matching community referral, so the screen becomes a tracked intervention. Gated by the SOCIAL_CARE feature.

Answer honestly — three states

Each domain is Yes / No / Not asked. "Not asked" is never treated as a negative, so population rates stay honest and you can come back and finish the screen later.

Close the loop

  1. Answer the domains and click Record screening.
  2. The positive findings table shows each positive need with its mapped Z-code and the suggested referral service.
  3. Add Z-code places the code (e.g. Z59.41 Food insecurity) on the problem list, citing the screening. (This is a problem-list write — it needs the GMPL PROBLEM key.)
  4. Create referral opens a Social Work referral to the matching service (Food, Housing, …) in the queue the social-work team already uses.
Demo: open patient P9301 (SOCIAL,SAM) — the seeded screen already shows food + housing positive with the Z-codes applied and referrals open. Population counts per domain are available via the API (/api/social-care/sdoh-cohort/{domain}).
