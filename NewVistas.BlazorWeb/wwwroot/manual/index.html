NewVistas User Manual

A modern clinical information system inspired by the VA's VistA EHR. Pick your role below — each manual shows only the workflows and screens that role uses, matching what you see when you sign in.

🩺

Physician

Cover sheet, orders, notes, prescribing (incl. the controlled-substance safety gate), problems, labs, consults.
🩹

Nurse

Vitals, nursing assessments, shift handoff, care plans, triage, task worklist, BCMA.
💊

Pharmacist

Verify & fill, DUR, interaction screening, EPCS, POS claims, drug accountability.
⚙️

Administrator

Registration, ADT, patient merge, site parameters, security keys, federation.

Editions

NewVistas runs as plain VistA (the baseline everyone has), with RPMS feature modules for IHS sites, and with Modern enhancements that go beyond core VistA/RPMS. Each site turns the extra modules on or off, so some screens and steps appear only on certain editions. Throughout the manual a small badge marks anything that isn't plain VistA, along with the feature flag that gates it:

VistA core — always available RPMS IHS feature module Modern enhancement beyond core VistA/RPMS

This is a local manual — no internet or server required. Open index.html in any browser. Each role manual shows only that role's workflows.
