Vital Signs

Record up to eight vital types for a patient, see abnormal values flagged in red automatically, and search the vital history by date or type. This is the equivalent of the CPRS Vitals package.

Open the Vitals screen

  1. In the sidebar, under Nursing, click Vitals (or go to /vitals).
  2. In the Patient ID field, type the patient ID (e.g. 9).
  3. Click Load. If no vitals exist yet, the View Vitals tab shows "No vitals recorded."

Record a set of vitals

  1. Click the Record Vitals tab.
  2. Fill in the header fields — Date/Time Taken (leave as now), Location (e.g. Ward 3A), and Entered By (e.g. JOHNSON,MARY R).
  3. Fill in the Vital Measurements grid — Temperature (F), Pulse (bpm), Respiration (breaths/min), Blood Pressure (mmHg, e.g. 120/78), Weight (lbs), Height (in), Pain (0–10), and Pulse Oximetry (%).
  4. Click Record Vitals.

A green banner reads "Vitals recorded successfully" and the page switches to the View Vitals tab, which shows one row per vital type with its latest value and the date/time taken. A new recording replaces the latest reading for each type you entered; types you left blank keep their previous value.

You don't have to enter all eight Enter as many or as few vitals as you took — for example just Blood Pressure and Pulse Oximetry. You must enter at least one measurement, though: submitting with every field blank returns the error "Enter at least one vital measurement" and saves nothing.

Reading the abnormal flags

The View Vitals tab flags out-of-range values automatically. A flagged value appears in red, bold text (the value.flagged style). The same red = danger color scheme runs through labs and the cover sheet, so an abnormal vital is recognizable at a glance.

  • Blood Pressure 180/110 — flagged (hypertension).
  • Temperature 104.2 — flagged (high fever).
  • Pulse 118 — flagged (tachycardia).
  • Respiration 26 — flagged (tachypnea).
  • Pulse Oximetry 89 — flagged (hypoxia).

⚠ Pain > 0 requires follow-up Whenever you record a pain score above 0, nursing protocol requires a formal structured pain assessment within one hour. After saving, go to /pain-assessment to document it.

Search the vital history

  1. Click the Vital History tab.
  2. Set the From and To dates (e.g. the last 30 days), choose a Vital Type (ALL or a single type such as BLOOD PRESSURE), and a Max Results limit.
  3. Click Search.

The results table shows each entry's vital type, value, units, flag, and date/time, sorted newest first, with a result count above the table (e.g. "12 result(s)"). Filtering by a single vital type shows only that type's readings.
