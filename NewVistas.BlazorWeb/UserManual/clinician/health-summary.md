# Health Summary

This guide covers the Health Summary module in NewVistas, which generates configurable clinical summary reports from the patient's electronic health record. Health summaries aggregate data from multiple clinical domains into a single, printable report that can be used for care coordination, patient handoffs, referral documentation, and clinical review.

**Route:** `/health-summary`
**VistA File:** #142 (Health Summary)

The Health Summary module maps to the VistA Health Summary package, which allows clinicians to define report templates specifying which clinical components to include and then generate reports on demand for any patient.

---

## Overview

The Health Summary module is organized into three tabs:

1. **Generate Summary** -- Select a summary template and generate a report for the current patient.
2. **Summary History** -- View previously generated summary reports.
3. **Summary Types** -- Create and manage summary templates that define which clinical components are included in reports.

---

## Tab 1: Generate Summary

The Generate Summary tab is the primary interface for creating health summary reports. It allows you to select a pre-defined summary template, generate the report, and then view, print, or export the results.

![Generate summary form with template selection and generated report](screenshots/health-summary-generate.png)

### Generating a Health Summary Report

1. Navigate to the Health Summary module at `/health-summary`.
2. On the **Generate Summary** tab, select a **Summary Type** from the dropdown. The dropdown lists all active summary templates available at your facility (e.g., "Primary Care Summary", "Pre-Operative Summary", "Mental Health Summary").
3. Click **Generate** to create the report.
4. The system queries each clinical domain specified in the summary template and assembles the results into a formatted report.
5. The generated report appears below the form, organized into sections based on the template's component list.

### Report Structure

A generated health summary report contains the following elements:

#### Report Header

| Field | Description |
|---|---|
| **Patient Name** | Full name of the patient |
| **Patient ID** | Patient identifier (e.g., SSN last 4, medical record number) |
| **Date of Birth** | Patient's date of birth |
| **Summary Type** | Name of the summary template used |
| **Generated Date** | Date and time the report was generated |
| **Generated By** | Name of the clinician who generated the report |
| **Facility** | Facility where the report was generated |

#### Report Sections

Each clinical component included in the summary template appears as a separate section in the report. Section content varies by component type but follows a consistent format:

- **Section Title** -- Name of the clinical component (e.g., "Active Problems", "Current Medications")
- **Content** -- Tabular or narrative data pulled from the patient's clinical record
- **Date Range** -- The time window of data included (if applicable to the component)

#### Available Clinical Components

The following clinical components can be included in a health summary template:

| Component | Description | Data Source |
|---|---|---|
| **Active Problems** | Current active problem list with ICD-10 codes, onset dates, and status | Problems module |
| **Inactive Problems** | Historical inactive and resolved problems | Problems module |
| **Allergies** | Documented allergies and adverse reactions with reaction type and severity | Allergies module |
| **Current Medications** | Active outpatient and inpatient medications with dose, route, frequency, and prescribing provider | Medications module |
| **Recent Labs** | Laboratory results from the specified time window, organized by test type | Labs module |
| **Recent Vitals** | Vital sign measurements from the specified time window | Vitals module |
| **Active Orders** | Current active orders across all order types (lab, pharmacy, radiology, consult, nursing) | Orders module |
| **Recent Notes** | Clinical notes (progress notes, discharge summaries, consult notes) from the specified time window | Notes module |
| **Immunizations** | Complete immunization history | Immunizations module |
| **Immunization Forecast** | Current vaccine recommendations based on CDC schedules | Immunization Forecast module |
| **Clinical Reminders** | Status of all clinical reminders (Due, Done, Applicable, Not Applicable) | Reminders module |
| **Appointments** | Scheduled appointments within the specified time window | Appointments module |
| **Consults** | Consult requests and results from the specified time window | Consults module |
| **Radiology Reports** | Radiology study results and interpretations from the specified time window | Radiology module |
| **Surgical History** | Completed surgical procedures with dates, surgeons, and outcomes | Surgery module |
| **Mental Health Screenings** | Mental health screening results with scores and interpretations | Mental Health module |
| **Health Factors** | Documented health behaviors and risk factors | Health Factors module |
| **Care Team** | Current care team members with roles and assignment dates | Care Team module |
| **Demographics** | Patient demographic information including address, phone, emergency contact, and insurance | Patient registration |
| **Advance Directives** | Documented advance directives, living will, and healthcare power of attorney | Notes module |

### Printing and Exporting

After generating a health summary report:

- **Print** -- Click the **Print** button to send the report to your local printer. The report is formatted for standard letter-size paper.
- **Export** -- Click the **Export** button to download the report. Exported reports can be used for patient handoffs, referral documentation, or external communication.

> **Tip:** Generate a "Pre-Operative Summary" for surgical patients to provide the surgical team with a comprehensive clinical overview including active problems, medications, allergies, recent labs, and advance directives.

## Tab 2: Summary History

The Summary History tab displays a chronological list of all health summary reports previously generated for the selected patient.

| Column | Description |
|---|---|
| **Date Generated** | Date and time the report was created |
| **Summary Type** | Name of the summary template used |
| **Generated By** | Provider who generated the report |
| **Sections** | Number of clinical components included in the report |
| **Actions** | View or print the previously generated report |

Click **View** on any historical report to display it. The report reflects the patient's clinical data as it existed at the time the report was generated, providing a point-in-time snapshot.

> **Note:** Historical health summaries are static snapshots. They do not update to reflect changes made to the patient's record after the report was generated. To see current data, generate a new report.

## Tab 3: Summary Types

The Summary Types tab allows authorized users to create and manage health summary templates. Each template defines a set of clinical components to include when a report is generated using that template.

### Summary Types List

The Summary Types list shows all defined templates:

| Column | Description |
|---|---|
| **Name** | Name of the summary type (e.g., "Primary Care Summary", "Mental Health Summary") |
| **Components** | List of clinical components included in the template |
| **Active** | Whether the template is active and available for use (Yes/No) |
| **Actions** | Edit or deactivate the template |

### Creating a Summary Type

To create a new health summary template:

1. Navigate to the **Summary Types** tab.
2. Click **New Summary Type**.
3. Enter a **Name** for the template (e.g., "Cardiology Referral Summary").
4. Select the **Components** to include in the template. Check the box next to each clinical component that should appear in reports generated with this template.
5. Verify that the **Active** flag is set to Yes.
6. Click **Save** to create the template.

### Editing a Summary Type

1. Locate the summary type in the Summary Types list.
2. Click the **Edit** action button.
3. Modify the name, add or remove components, or change the active status.
4. Click **Save** to apply the changes.

> **Note:** Editing a summary type affects future reports generated with that template. Previously generated reports are not modified.

### Deactivating a Summary Type

To remove a summary type from the available template list without deleting it:

1. Locate the summary type in the Summary Types list.
2. Click **Edit**.
3. Set the **Active** flag to No.
4. Click **Save**.

Deactivated templates no longer appear in the Generate Summary dropdown but remain in the Summary Types list for reference. They can be reactivated at any time.

### Example Summary Types

Facilities commonly define the following summary types:

| Summary Type | Typical Components |
|---|---|
| **Primary Care Summary** | Active Problems, Allergies, Current Medications, Recent Labs (6 months), Recent Vitals (3 months), Clinical Reminders, Immunizations, Health Factors, Care Team |
| **Pre-Operative Summary** | Active Problems, Allergies, Current Medications, Recent Labs (30 days), Recent Vitals (7 days), Surgical History, Advance Directives, Care Team |
| **Mental Health Summary** | Active Problems, Current Medications, Mental Health Screenings, Recent Notes (6 months), Health Factors, Care Team |
| **Discharge Summary** | Active Problems, Allergies, Current Medications, Active Orders, Recent Labs (during admission), Recent Vitals (during admission), Recent Notes (during admission), Appointments, Care Team |
| **Referral Summary** | Active Problems, Allergies, Current Medications, Recent Labs (3 months), Consults, Radiology Reports (6 months), Care Team |
| **Comprehensive Summary** | All available components |

> **Tip:** Work with your facility's clinical leadership to establish a standard set of summary types that meet the needs of your clinical workflows. Consistent templates ensure that all providers have access to the same report formats.

## Common Workflows

### Generating a Summary for a Patient Handoff

1. Navigate to `/health-summary`.
2. Select the appropriate summary type for the handoff scenario (e.g., "Discharge Summary" for an inpatient-to-outpatient transfer, "Referral Summary" for a specialty referral).
3. Click **Generate** to create the report.
4. Review the generated report for completeness and accuracy.
5. Click **Print** or **Export** to produce a copy for the receiving provider.

### Creating a Custom Summary Type for Your Service

1. Navigate to the **Summary Types** tab.
2. Click **New Summary Type**.
3. Enter a descriptive name that identifies the purpose and service (e.g., "Endocrinology Clinic Summary").
4. Select the clinical components relevant to your service's needs.
5. Save the template.
6. Inform your colleagues that the new summary type is available.

### Reviewing a Historical Summary

1. Navigate to `/health-summary` and click the **Summary History** tab.
2. Browse or search the list of previously generated reports.
3. Click **View** on the report of interest to display it.
4. Compare the historical snapshot with the patient's current clinical data to identify changes over time.
